# Assignment 2-3 Part B – IDE Features Reflection

## Introduction

> My experience using the course IDE to complete my first programming assignment was pretty straightforward while having zybooks as a template. I enjoyed being able to write my own code and see it turn into a working program that someone else could use. Three features i found useful were Syntax Highlighting, problems panel and integrated terminal.

## Feature 1 - Syntax Highlighting

> One feature i found useful was the Syntax Highlighting feature. When i was replacing the original prompts with my own code, the different colors helped certain things stand out immediately. This made it easier to recognize different parts of the code and notice possible errors. It also kept everything visually organized and made it easy to navigate the program i find where i needed to go and where to put different punctuations. Overall very helpful for beginning programmers like myself.

## Feature 2 - Problems Panel

> The second feature i found useful was the problems Panel. At first, i wasn't sure where to find this feature when looking for errors in my code. I wish it stood out more so beginning programmers could locate it easily. Once I found it, i liked how it pointed out problems, such as lines being too long, and helped me identify what needed to be corrected. I also liked that VS Code sometimes provided suggestions to fix the misspelled words without retyping. One Improvement i would recommend is having an option to automatically shorten lines that are too long. Overall, i think the Problems Panel makes programming easier because it helps correction easier before running the program and testing it out.

Feature 3 – Integrated Terminal

> The third IDE feature I found useful was the Integrated Terminal. This feature further helped my programming experience because it allowed me to run and test my Python code directly in Visual Studio Code without having to open extra windows or browsers. I liked how straightforward the process was and how I could immediately see the results after entering my name and age. It made testing my program easier and helped me keep everything organized in one place. I think this feature is especially useful for beginning programmers because it makes running and checking code more convenient without having to switch between different windows.

Conclusion

> Overall, I think these  IDE features i picked will definitely help me with future programming assignments. I now have a better understanding of where to find them, what they do, and how to use them. There may still be other functions within these features that I haven't explored yet, but I feel more comfortable using Visual Studio Code. I believe these features will make future assignments easier to complete and help me gradually improve my programming skills as I gain more experience.
